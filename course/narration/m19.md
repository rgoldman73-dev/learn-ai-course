# m19 narration: Shared interfaces

Welcome to Module Nineteen, the last module of the unit on niches and tools.

A bee landing on a flower it has never met before still knows, roughly, what to do. Over a very long time, flowers and pollinators have converged on shared cues. Nectar guides that glow in ultraviolet. Landing platforms. Colours and scents that mean, reward here. Because the signal is standard, any compatible pollinator can work any compatible flower, and the whole network becomes richly connected.

The Model Context Protocol, usually just called M C P, is the agent world's shared cue. A service that offers an M C P server can be used by any agent that speaks M C P. And the agent can ask any such server a simple question: what tools do you have? That one listing step is what lets a new partner be useful right away.

M C P is different from yesterday's skills. A skill is a folder of instructions the agent reads itself. An M C P server is a separate running program that the agent talks to. They work well together.

Now scale it up. Uber described what happened when hundreds of their teams started connecting agents to internal services, each in their own way. Tools were scattered, duplicated and hard to find, and security was inconsistent. So they built a gateway. One place that keeps a catalogue of every server and tool, checks who is calling, removes personal data from responses, and translates agent calls into the language of each internal service. Two of their design choices are worth stealing. First, discovery does not mean exposure. Automatically generated tools start switched off, until the owning team reviews and enables them. Second, with thousands of tools, you can't show them all to a model. So the agent searches for a server, then looks up its tools, then fetches only the one it needs. You've now met that same pattern three times. It's called progressive disclosure.

You can also reshape the agent itself. Claude Code mods are small programs that watch everything happening in a session. They can observe an event, rewrite it, or answer it themselves, for example by refusing a dangerous command before it runs.

Here's where the pollination story breaks. Mutualisms evolve slowly, and cheaters are kept in check by slow ecological feedback. An M C P server, written by a stranger, can join your agent in seconds, and whatever its tools say flows straight into your agent's context. Trust can't evolve here. You have to manage it on purpose.

In the lab, you'll connect a free browser server to your capstone project, use it to read one public species page and pull out its taxonomy, and then build a guard that blocks destructive commands. Then you'll ask your agent to delete a folder, and watch the guard say no.

Together with yesterday's skill, that's your build for this unit. Let's go and open some flowers.
