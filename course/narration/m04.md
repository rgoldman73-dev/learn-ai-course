# m04 narration: Carrying capacity

Welcome to Module Four, and to Unit Two: context is habitat.

You know carrying capacity. Every habitat supports only so many individuals. Below that limit, adding one more is cheap. Near it, crowding hurts everyone. Resources thin out, interference rises, and the whole population does worse.

A language model has a habitat too. It is called the context window, the amount of text the model can hold in view at once. And everything has to live there. Your instructions. The files the agent opened. The output of every command it ran. Every correction you typed.

Here is the first surprise. The model has no memory between turns. Each time you send a message, the entire conversation is sent again and read again, from the very top. So a long session is not just long. It gets more and more expensive with every turn, because everything earlier is paid for again and again.

The second surprise is what actually fills the window. One of the Carnegie Mellon lecturers looked at fifteen hundred sessions of his team's coding agent. The biggest share was not the model's own words. It was tool results, the contents of files and the output of commands, at well over a third. The model's replies to the person were about two percent.

Providers soften the bill with a cache. If the beginning of the request is exactly the same as last time, that part is reused cheaply. But exactly means exactly. Put the time of day at the top of your instructions, switch models halfway through, or walk away for too long, and the cache is gone.

And a bigger window is not a better habitat. Models get worse at finding and using information as the window fills. They forget early instructions. One student in the lecture described telling an agent not to delete something, and it deleted it anyway.

When the window nears its limit, the harness compacts it. It squeezes older history into a summary and keeps the recent part. That is a bit like density-dependent regulation. But it loses things. One team's compaction passed every benchmark, then in real use their agent forgot it had already opened a pull request, and opened it five times.

So where does the metaphor fail? Food is eaten once. Context is re-read on every single turn. And crowding does not starve the model. It distracts it.

In today's lab you will measure this yourself. You will run one deliberately crowded session, check how full the window is, compact it, and test what the agent still remembers. Then you will clear it and run one small, focused task, and compare.

Open your terminal, and let's measure the habitat.
