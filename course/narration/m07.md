# m07 narration: Genome and body

Welcome to Module Seven, and to Unit Three: building an organism.

A genome, on its own, does nothing. It needs a body. Sense organs to take in the world. Limbs to act on it. A metabolism that keeps the cycle going. An immune system that rejects what is dangerous. And some way to remember what happened yesterday.

In the first unit, you saw how a model is trained. Those trained weights are the genome. Today we look at the body, which builders call the harness. The formula you will see again and again is simple. An agent is a model plus a harness.

Here is why that matters. The model itself only does one thing. Text goes in, text comes out. It cannot open a file. It cannot run a command. It cannot remember last week. Every one of those abilities comes from the harness wrapped around it.

The heart of every harness is a loop, and it really is that simple. Send the model the task and everything that has happened so far. The model either asks to use a tool, or gives a final answer. If it asks for a tool, the harness runs it, adds the result to the history, and asks again. Round and round, until the model stops asking, or the harness says enough.

A team of researchers took apart the source code of eleven real coding agents, including Claude Code and Codex. They found that every single one is built from the same seven parts. The loop. The connection to the model. The tools. Memory and context. Safety and permissions. The ability to start helper agents. And ways to extend it, with things like skills and plugins. The smallest one is about a hundred lines of code. The biggest is enormous. And here is the surprise: on benchmarks, the tiny one does about as well. What the big ones buy is safety, recovery, and control.

This anatomy is a powerful diagnostic tool. If your agent keeps redoing yesterday's work, it is missing memory. If it guesses your conventions, it is missing context. If it hands you broken work and calls it finished, it is missing verification. Fix the missing layer before you blame the model.

And where does the metaphor fail? A body grows from its genome. The two evolved together and cannot be pulled apart. A harness is built separately, and you can swap it under the same model. One team moved their agent from the top thirty to the top five on a public benchmark by changing only the harness. Imagine moving a genome into a new body and watching it run faster.

In today's lab, you will ask your own coding agent to describe its own body, part by part, and to admit which parts it is guessing about. You will save that as a blueprint in your capstone. Tomorrow, you build a body of your own.

Open your terminal, and let's dissect.
