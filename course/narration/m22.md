# m22 narration: The field notebook

Welcome to Module Twenty-Two, the last module of the unit on retrieval and memory.

Every field biologist learns this lesson the hard way. You will not remember it. Not the date, not the weather, not the strange behaviour you were sure you'd never forget. So you write it in the notebook. And the herbarium keeps the voucher specimen, with its label, long after the collector has retired. External memory is what lets an expedition's knowledge outlive the expedition, and lets someone else check it, decades later.

Agents need exactly the same thing.

Think of agent memory in three layers. The first is working memory, the context window. Everything the model can attend to right now. It's limited, and when it fills up, the model gets worse and starts forgetting your early instructions. And when the session ends, it's gone.

The second layer is compaction. When the window fills, the older part of the conversation is replaced by a summary. That keeps the session going, but it loses detail, and it loses more every time it happens. The CMU course tells a good story here. One research group built a compaction method that looked perfect on a benchmark. Then, in real use, their agent kept forgetting it had already opened a pull request, and opened the same one five times. Benchmarks can hide memory failures.

The third layer is external memory: files and databases that survive between sessions. The agent reads and writes them with its tools. One of today's sources sums it up in a single line. If it isn't in a file, it doesn't exist.

The people building second brains with Claude Code have converged on a simple design. Plain text notes. One topic per file, named for what's in it. A few clear folders. And one index file at the top that tells the agent where everything lives and how to behave. Answer only from my notes. Cite the note. And if the answer isn't there, say so.

They also make big promises. Perfect memory. A system that gets smarter on its own. Treat those as hypotheses, because here's where the herbarium metaphor fails. A specimen is fixed. Nobody can quietly re-press the plant. Agent memory is rewritten by the agent. Every time it files a note, summarises, or updates a fact, a model is deciding what to keep. An early misreading can be stored, cited back to you as evidence, and reinforced every time it's found. So keep the raw originals, never let the agent delete, and audit it.

That's the lab. You'll build your capstone's field notebook, with a map file and two commands: one that files your raw notes into tidy, linked pages, and one that answers questions from them with citations. Then you'll test its recall with ten questions you already know the answers to. Two of them aren't covered by your notes at all. The question is whether your notebook admits it.

Open the reading, and start your notebook.
