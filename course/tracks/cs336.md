# Build track: Stanford CS336, Language Modeling from Scratch

**What it is.** Stanford CS336 (Spring 2026), taught by Percy Liang and Tatsunori Hashimoto, takes you through building a language model end to end: tokenizer, transformer, GPU kernels, parallel training, scaling laws, data pipelines, evaluation and post-training. All 18 recorded lectures (17 plus a guest lecture by Dan Fu) are on YouTube, and the five assignment handouts and starter code are public on GitHub. One assignment is writing FlashAttention in Triton. [S:2112907915694936123]
[Course site](https://cs336.stanford.edu/) · [YouTube playlist](https://www.youtube.com/playlist?list=PLoROMvodv4rMqXOcazWaTUHhq-yembLCV) · [Assignments (GitHub)](https://github.com/stanford-cs336)

This is an optional companion track and the hardest one in the app. Learn AI teaches what a model and harness *do*. CS336 is how you *build the model itself*.

> Honest limits: Stanford calls it "very implementation-heavy" (5 units), with minimal scaffolding and an order of magnitude more code than other classes. The prerequisites are fluent Python and PyTorch, the basic GPU memory hierarchy, linear algebra, probability and an intro ML course. The [Math track](#/track/mml) covers the maths. Assignments 2 onwards want a real GPU (rented cloud GPUs are fine). You can watch the lectures without doing any of that.

## Assignments (do 1 first, the rest are optional)

1. **Basics.** Write a BPE tokenizer, a transformer LM, AdamW and a training loop, then train a small LM. This is the one assignment to do if you do any.
2. **Systems.** Profile and benchmark, write FlashAttention-2 in Triton, distributed data parallel.
3. **Scaling.** Fit scaling laws on a query budget.
4. **Data.** Filter and deduplicate Common Crawl.
5. **Alignment.** SFT and RL with verifiable rewards (GRPO) on maths reasoning.

## A pace that fits

Two lectures a week alongside Units 6–7 of Learn AI gives about 9 weeks. Watch at 1.25×. After each lecture, ask the library a question (below) and add the answer to your module notes.
